# PlayGround

## 🦖 Jurassic Park: The Lost Island

A complete, single-file pixel-art adventure inspired by Jurassic Park. The game is
rendered procedurally on an HTML5 canvas (no external images or audio files) and
runs directly in the browser.

- **História em 5 capítulos:** chegada, parque, falha de energia, reino do T-Rex e fuga.
- **Modo livre:** construa cercados, laboratórios, centros, restaurantes, estradas,
  lagos, torres e solte dinossauros; acompanhe visitantes, receita e segurança.
- **12 espécies** com sprites distintos, IA, fome, energia, descanso, alimentação,
  rugidos e animações de caminhada/corrida.
- **Sistemas:** missões, scanner, inventário, mapa com viagem rápida, conquistas,
  galeria animada, diálogos, gerenciamento do parque e salvamento automático.
- **Mundo vivo:** ciclo dia/noite, chuva, tempestades, relâmpagos, folhas, pássaros,
  vaga-lumes, cachoeira e cenas cinematográficas.
- **Áudio sintetizado:** trilha, chuva, trovões, rugidos e efeitos via WebAudio.
- **Mobile:** joystick virtual e botões de toque (correr, pular, usar, mapa, mochila,
  obras, missões, galeria e câmera); visão letterbox sem distorção.

### Jogar

Abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

### Controles

| Ação | Teclado |
| --- | --- |
| Mover | WASD / setas |
| Correr | Shift |
| Interagir / escanear | E |
| Pular | Espaço |
| Inventário / galeria | I / G |
| Missões / mapa | Q / M |
| Construir (modo livre) | B |
| Câmera | C |
| Pausa | Esc / P |

No celular use o joystick à esquerda e os botões à direita. Gire a tela para uma
visão maior.

O progresso é salvo automaticamente em `localStorage` (chave `jurassicLostIsland.v3`).
